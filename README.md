#Tahmid's Projects

A collection of projects built in C++, Python, Yacc, and Lisp

## Projects

### Farm
Developed a C++ farm simulation application utilizing object-oriented programming, inheritance, polymorphism, dynamic memory management, and vector-based data structures to model seasonal farming operations.

### Lex and Yacc
Built a calculator interpreter using Lex and Yacc by modifying a starter grammar from infix notation to prefix notation. Added support for arithmetic, variable assignment, comparison operators, logical operators (and, or, not), and a ternary-style if operator by updating both the lexer and parser grammar.

### Retriever Bell
A Python-based command-line application that simulates a telephone switchboard network. 
Users can create switchboards (area codes), connect them through trunk lines, add phone numbers, initiate and end phone calls, and display the current network state.
The program uses recursive graph traversal to determine whether two phones can communicate through connected switches and supports saving/loading network configurations through file persistence.

### Song Player 
Developed a menu-driven music playlist manager in C++ that loads song data from a file, supports searching by title or artist, allows users to build and sort playlists, and utilizes custom templated queue data structures, dynamic memory management, and object-oriented programming principles.

### Uno
This project is a simplified two-player UNO-style card game written in Python. It creates and shuffles a deck, deals cards to two players, tracks a draw pile and discard pile, and lets players take turns playing matching cards by color, number, or special type. The game supports special cards like Skip, DrawTwo, Wild, and WildDrawFour, and ends when one player empties their hand or the draw pile runs out, resulting in a tie.

### Election Simulator
Developed a C++ program that reads vote data from a file, counts votes for candidates using parallel arrays, normalizes name capitalization, and displays results as vote totals and histograms. Demonstrates file I/O, arrays, string manipulation, functions, input validation, and basic data processing.
